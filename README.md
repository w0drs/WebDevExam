# Электронная библиотека

## Описание проекта

Автоматизированная информационная система для ведения реестра книг и читателей, поиска книг и оставления рецензий.

## Технологический стек

- **Backend**: Python 3.11, Flask
- **База данных**: PostgreSQL
- **ORM**: SQLAlchemy
- **Аутентификация**: Flask-Login
- **Frontend**: HTML5, CSS3, Jinja2, EasyMDE

## Функциональные возможности

### Для неаутентифицированных пользователей
- Просмотр главной страницы со списком книг
- Просмотр страницы входа в систему
- Просмотр информации о книге (обложка, описание, рецензии)

### Для аутентифицированных пользователей
- Вход и выход из системы
- Просмотр списка книг с пагинацией (10 книг на странице)
- Сортировка книг по году выпуска (сначала новые)

### Для пользователя с ролью «Пользователь»
- Оставление рецензий на книги с оценкой от 0 до 5
- Поддержка Markdown при написании рецензии
- Просмотр всех своих рецензий в разделе «Мои рецензии»
- Отслеживание статуса рецензии (на рассмотрении, одобрена, отклонена)

### Для пользователя с ролью «Модератор»
- Редактирование информации о книгах
- Модерация рецензий: одобрение или отклонение
- Просмотр списка рецензий на рассмотрении с пагинацией

### Для пользователя с ролью «Администратор»
- Создание, редактирование и удаление книг
- Загрузка обложек для книг
- Полный доступ ко всем функциям системы

## Структура базы данных

### Таблицы

| Таблица | Назначение |
|---------|------------|
| roles | Роли пользователей (Администратор, Модератор, Пользователь) |
| users | Пользователи системы |
| genres | Жанры книг |
| books | Книги |
| book_genres | Связь книг и жанров (многие ко многим) |
| covers | Обложки книг |
| review_statuses | Статусы рецензий (на рассмотрении, одобрена, отклонена) |
| reviews | Рецензии на книги |

### Особенности реализации
- Каждая книга может иметь несколько жанров
- Обложки хранятся с вычислением MD5-хэша для предотвращения дублирования
- При удалении книги каскадно удаляются связанные записи (обложка, рецензии, связи с жанрами)
- Файл обложки также удаляется из файловой системы

## Установка и запуск

### Локальный запуск

1. Клонировать репозиторий
2. Создать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate     # Windows
   ```
3. Установить зависимости:
```bash
pip install -r requirements.txt
```
4. Создать базу данных PostgreSQL
5. Настроить переменные окружения в файле .env
6. Выполнить инициализацию базы данных:
```bash
python app.py
```

### Запуск через Docker
```bash
docker-compose up --build
```

## Переменные окружения (.env)

```ini
# Flask
SECRET_KEY=your-secret-key

# Database
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=12345
DB_NAME=electronic_library

# Upload
UPLOAD_FOLDER=static/uploads
MAX_CONTENT_LENGTH=16777216

# Pagination
BOOKS_PER_PAGE=10
REVIEWS_PER_PAGE=10
```

### Примечания
- Текст перед сохранением проходит санитайзер для предотвращения XSS-атак
- Обложки загружаются только при создании книги и не подлежат редактированию
- Пагинация реализована на главной странице и в разделе модерации рецензий
- Модальное окно с подтверждением используется при удалении книг
